# SUTD 1d itp project
## get started:
1. install uv
2. https://docs.astral.sh/uv/getting-started/installation/
3. after that, go here, type in uv sync
4. done! uv run to start.

## requirements:
* Your webapp must be relevant to the scenario given in this project brief 
i.e. a webapp to solve a problem in a theme park and not anything else (i.e. no games or apps related to other themes) 
* Your webapp must be programmed only using Streamlit and use Python only. However, you can use HTML, CSS and/or Markdown syntax in the Streamlit methods which require them. 
* You may not use any other front-end libraries.
